# Frontend

Vite + React frontend for the Credit Wallet project.

## Local run

1. Install deps

```bash
cd Frontend
npm install
```

2. Start dev server

```bash
npm run dev
```

3. Configure API

Set `VITE_API_BASE` in `Frontend/.env` (defaults to `http://localhost:5000/api`).
